# 사람 검출기 선택 권고 (벤치마크 v3 검토)

대상 환경: CPU 전용 (i7-1165G7, ONNX Runtime, Windows), FastAPI 사진 서비스, 군중 사진 다수, 응답 수백 ms~1 s.
근거 자료: results_v3.json (GT v3, k>=6, LOO), summary_v2.md (GT v2), gt_overlays, 그리고 검토자가 cache/·cache_v3/ 로 추가 계산한
결과 (가족 제외 GT, 비-Ultralytics GT, 점수 0.25 기준 GT, 이미지 단위 부트스트랩 4000회).

## 1. 타당성 평가 (핵심 3가지 + 보조)

**(A) 타일 모드 F1@0.25 는 순위용으로 쓸 수 없음. Ultralytics 가 1위인 것은 GT 점수 컷 때문이고, 같은 계열끼리의 합의 효과가 아님.**
- 계열 상관 가설은 기각됨: k>=6 GT 175개 중 Ultralytics(v8/11/10) 지지를 빼면 탈락하는 박스는 7개뿐.
  scored 모델의 계열 전체를 GT 에서 빼도 YOLOv8m 타일 F1 은 0.890 -> 0.892, Ultralytics 8종 전부를 빼도 (k>=5) 0.881 (변화 0.01 이내).
- 실제 원인: GT 는 점수 >=0.40 인 검출로 만들고, 평가는 >=0.25 에서 함. [0.25, 0.40) 구간 검출의 GT 적중률(정밀도)은
  YOLOX-x 0.00, YOLOX-m 0.08, RT-DETR-R50 0.08, DETR 0.00 이고, Ultralytics 는 0.67~0.96.
  저점수 구간이 GT 에 실제로 없는 사람(=GT 누락)인지 오검출인지는 이 데이터로 구분할 수 없음.
- GT 를 점수 >=0.25 검출로 다시 만들면 순위가 뒤집힘: YOLOX-x 0.751 -> 0.842, YOLOX-m 0.759 -> 0.851, YOLOv8m 0.890 -> 0.799.
- 타일 F1@0.25 와 타일 AP50 의 순위 상관(Spearman)은 -0.03. 두 지표가 서로 다른 것을 재고 있음.

**(B) GT 가 실제 인원의 약 27% (175 / 약 645) 라서 precision 과 F1 은 재현율이 높은 모델을 과소평가함.**
- overlay 확인 결과: 쇼핑몰 중경 군중, 경기장 중·후열의 뚜렷이 보이는 사람 수십 명이 GT 에 없음. tiny(<32px) GT 는 0개.
- 같은 모델도 GT 가 커질수록 precision 이 올라감: RT-DETR-R50 표준 모드 P@.25 는 v2 (GT 112명) 0.566 -> v3 (GT 175명) 0.757.
  이른바 오검출 상당수가 실제 사람이라는 뜻. 따라서 표준 모드의 RT-DETR/DETR/YOLOX-x 점수도 하한값으로 봐야 함.
- 같은 이유로 best_f1_thr 은 실제 최적값보다 높게 잡혔을 가능성이 큼. 또 sweep 하한이 0.25 라서, 0.25 에서 최고가 나온 모델은 진짜 최적값이 더 낮을 수 있음.

**(C) 표본이 작음 (이미지 6장). 표준 모드 AP50 차이가 약 0.08 보다 작으면 순위를 구분할 수 없음.**
- 이미지 단위 짝지은 부트스트랩: 모든 모델 쌍의 AP50 차이에 대한 95% CI 반폭 중앙값 0.079 (IQR 0.063~0.094).
  표본이 6장뿐이라 부트스트랩 CI 도 실제보다 좁게 나왔을 수 있음.
- 유의한 차이 (CI 가 0 을 포함하지 않음): RT-DETR-R50 > YOLOX-x +0.068 [+0.020, +0.114]; RT-DETR-R50 > R18 +0.106;
  YOLOX-s > YOLOX-Tiny +0.197; NanoDet-1.5x > YOLOX-Tiny +0.177; YOLOv6-N > NanoDet-1.5x +0.062; RT-DETR-R18 > YOLO11s +0.159.
- 동률 (구분 불가): RT-DETR-R18 vs YOLOX-m +0.039 (P=0.74), YOLOv6-S vs YOLOv6-N +0.001, YOLOX-l vs YOLOX-m -0.027.

**보조 관찰**
- 표준 모드 순위는 GT 를 어떻게 만들든 안정적임: LOO GT 와 비-Ultralytics GT 사이의 Spearman 은 F1 0.995, AP50 0.993.
  표준 모드 안에서 F1 과 AP50 의 순위 상관은 0.87.
- DETR/RT-DETR 은 F1@0.25 에서 손해를 봄: DETR 표준 F1@.25 0.613 vs best_f1 0.725 (임계값 0.65), RT-DETR-R50 0.771 vs 0.790 (임계값 0.30).
  RT-DETR 은 임계값에 민감함: R18 기준 F1 이 0.30 에서 0.728, 0.40 에서 0.560.
- YOLOv10 은 점수가 낮게 압축돼 있음: [0.25, 0.40) 구간 적중률 0.85~0.96 인데 표준 모드 재현율은 0.26~0.29.
  0.25 미만 검출이 캐시에 없어서 더 낮은 임계값의 성능은 측정할 수 없음.
- 타일 모드는 GT 를 타일 검출로 만들었기 때문에 표준 모드보다 유리함. 표준 vs 타일 비교 수치(dAP50 +0.11~+0.42)는 과대 추정임.

**피할 것**
- YOLOX-Tiny 416 (현재 앱): AP50 0.359, recall_small 0.075. 같은 속도의 NanoDet-1.5x 보다 AP50 이 0.177 낮음. 현재 conf 0.35 에서는 F1 0.399 (0.25 에서는 0.490).
- YOLOv8/YOLO11 (표준 모드): AGPL-3.0 이고 표준 AP50 0.35~0.52, recall_small 0.06~0.25. 타일 F1 1위는 위 (A) 의 인공물.
- YOLOv10n/s: 표준 AP50 0.260/0.282, YOLOv10s 의 recall_small 0.000. 점수가 압축돼 있고 AGPL-3.0.
- SSD-MobileNetV1: 표준 AP50 0.138. 군중 사진에 쓸 수 없는 수준.
- YOLOX-x (표준): 1307 ms 인데 RT-DETR-R50(1002 ms) 보다 AP50 이 유의하게 낮음 (-0.068).
