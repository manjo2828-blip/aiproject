# llm-wiki 규칙

LLM 이 리서치/결정사항을 구조화해 누적하는 지식 베이스.

- `index.md` — 모든 페이지 목록 + 한 줄 요약 (새 페이지 만들면 반드시 등록)
- `models/<name>.md` — 모델별 페이지: 후보 비교, 최종 선택, 다운로드 URL, 입출력 형식, 전처리, 크기/속도, 라이선스, 함정
- `decisions/<NNN-title>.md` — 아키텍처 결정 (배경 / 결정 / 이유 / 대안)
- `raw/` — 원본 메모, 링크 덤프 (가공 전)
- 페이지 템플릿: `# 제목` / `> 한줄요약` / `## 핵심 사실` / `## 출처` / `## 관련 [[링크]]`
- 사실만 쓰고 추측은 "(미확인)" 표시. 날짜 기입.
