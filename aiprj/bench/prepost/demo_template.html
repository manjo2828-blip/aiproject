사람 검출 파이프라인 데모

군중 사진 6장과 5개 모델의 실제 검출 결과를 담았습니다. 모델, 신뢰도, 중복 제거 기준을 바꾸면 찾은 사람 수와 놓친 사람이 바로 다시 계산됩니다. 서버나 모델은 돌지 않고, 브라우저에서 미리 저장한 결과를 걸러내기만 합니다.

현재 상태: 표준 파이프라인(리사이즈 → 모델 → 디코딩 → 신뢰도 → NMS)의 기준선입니다. 전/후처리 개선(고해상도, 타일, 플립, 앙상블 등)은 아직 측정 전이라 맨 아래 목록에 '미측정'으로 두었습니다.

파이프라인

직접 조절해 보기

사진은 CrowdHuman 검증 세트(사람이 직접 라벨링)에서 뽑았습니다. 정답은 가려진 사람과 아주 작은 사람까지 모두 포함하므로, 어떤 모델도 전부 찾지는 못합니다.

찾음놓침오탐
이 값 이상인 박스만 사람으로 칩니다.
오른쪽 끝이면 끔. 낮출수록 겹친 박스를 더 많이 지웁니다.
모델 입력(전처리 결과)

모델별 기준선

100장 전체 평가 결과입니다. 오탐을 이미지당 2개까지 허용했을 때 찾은 사람 비율(recall@FPPI=2)이 같은 조건 비교 기준입니다. 지연은 CPU 4스레드 중앙값입니다.

모델recall@FPPI=2FPPI=5AP50지연(ms)크기(MB)라이선스

다음에 측정할 전/후처리

학습 없이 적용하는 기법만 모았습니다. 효과는 아직 이 데이터에서 재지 않았고, 순서대로 추가하며 측정합니다. 문헌 수치는 다른 데이터셋 기준이라 그대로 기대하면 안 됩니다.
