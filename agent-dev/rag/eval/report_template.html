하이브리드 서치 정량평가

Structured Parent-Child 청킹과 bge-m3 임베딩은 고정하고, BM25 쪽의 토크나이저·스코어링 방식·파라미터와 결합 가중치를 바꿔 가며 25,117개 설정을 같은 질의 60개로 평가했습니다.

BM25 단독

토크나이저가 스코어링 공식보다 크게 좌우합니다

한국어는 조사가 붙어 단어가 바뀌기 때문에 어떻게 쪼개느냐가 먼저입니다. 같은 토크나이저 안에서 Okapi, BM25L, BM25+, TF-IDF 차이는 0.01~0.02 수준이고, 토크나이저를 바꾸면 0.2까지 벌어집니다. 칸의 숫자는 기본값(k1=1.2, b=0.75)의 MRR@10이고, 괄호는 k1·b를 그리드로 튜닝한 최고값입니다.

명사만 쓰면 크게 떨어집니다. 질의의 핵심이 "깨웠나", "무너졌다" 같은 용언인 경우가 많아서, 명사만 남기면 신호가 사라집니다. 내용 형태소(체언+용언+부사)를 쓴 Kiwi가 가장 좋았습니다.
가중치

Dense와 BM25를 얼마나 섞을까

가로축은 Dense 비중입니다. 0이면 BM25만, 1이면 Dense만입니다. 선형 결합은 두 점수를 정규화한 뒤 w·dense + (1−w)·bm25로 합치고, RRF는 순위만 사용합니다. 세로축은 0.5부터 시작합니다.
